# Modal Folio Motion, Path Alias, Uniform Form Widths, and Scroll Containment

A unified visual and interaction pass across dialogs and settings:
1. **`luu:` Path Alias**: Paths inside the state directory (`sessions.db`, `config.toml`) are displayed as `luu:/…` with the full host path in the hover title, preventing truncation in tight stat cards and lists.
2. **Uniform `<dt>` Columns**: Form label columns in `.settings` share a uniform width (`9rem`) rather than sizing to `max-content` per list.
3. **Scroll Containment**: `<Scrollable>` defaults to `overscroll-behavior: contain`, preventing scroll chaining to parent windows.
4. **Folio Entrance for All Modals**: The 3D perspective tilt animation developed for Settings becomes the default entrance for all dialogs.

## Problem

### 1. Clipped paths in stat cards
In Settings → Models, the status grid displays the active storage path. An absolute path such as `/Users/joshua/.config/luu/sessions.db` exceeds 37 characters. In a 4-column responsive grid, the path was clipped (`/Users/joshua/.con…`) or forced horizontal scroll, obscuring the only piece of information that mattered: the file name. The same issue affected path notes in Engines, Runtimes, Providers, and Sessions.

### 2. Disjointed `<dt>` widths
Form lists used:
```css
.settings {
  display: grid;
  grid-template-columns: max-content 1fr;
}
```
Because `max-content` measures only within its own `<dl>`, adjacent sections had mismatched label gutters: a section with a long label like "Files are drawn by" indented its inputs further right than a section with "Name" or "Kind".

### 3. Scroll chaining
Scrollable areas (such as sandbox pre tags, terminal logs, or modal bodies) allowed scroll events at scroll boundaries to propagate to the parent viewport, causing unexpected page jitter when scrolling fast with a trackpad or mouse wheel.

### 4. Inconsistent modal transitions
While Settings opened with a tactile 3D folio swing (`perspective(1200px) rotateX(36deg)`), other modals (project switcher, context inspector, prompt viewer) popped in with flat opacity and 2D translation, making the UI feel fragmented.

## Solution

### 1. `luu:` Path Alias
- `/api/settings` exposes `home: String` via `serve::state_home()`, resolving the state directory non-interactively without terminal prompts.
- A dedicated `<PathText :path="..." :home="..." />` component (`web/components/path-text.html`) parses the path. If `path` starts with `home`, it prefixes `luu:` as an `<abbr class="alias" :title="home">` followed by the relative path (e.g., `luu:/sessions.db`).
- Integrated across Models, Providers, Engines, Runtimes, Resend, and Authority.

### 2. `--dt-width: 9rem`
In `web/app.css`:
```css
:root { --dt-width: 9rem; }
.settings {
  display: grid;
  grid-template-columns: var(--dt-width) minmax(0, 1fr);
  gap: .45rem 1rem;
}
.settings dt {
  overflow-wrap: anywhere;
}
```
All description lists in settings now align to a single 9rem column, wrapping gracefully if a label exceeds that width.

### 3. `overscroll-behavior: contain`
In `web/components/scrollable.html`:
- Added `overscroll = 'contain'` prop.
- Applied `overscroll-behavior: ${overscroll || 'contain'}` to `.scroller`.
- Inner scrolling now stops at boundaries without moving the parent document or modal container.

### 4. Global Folio Animation
In `web/components/modal.html`:
- All top-level `<dialog>` elements now open via `folio-down` (`perspective(1200px) rotateX(36deg) translateY(-14px) scale(.97)` pivoting around `50% 22%`) and close via `folio-up`.
- `dialog.child` retains its targeted sheet animation (`sheet-in` / `sheet-out`), dropping from under the parent's header.

### 5. `section.modal-body.pane` Padding and Scroll Containment
In `web/app.css` and `web/views/settings/settings.html`:
- Added `.modal-body.pane { padding: 1.25rem 1.75rem 2.5rem; scroll-padding-bottom: 2.5rem; }` ensuring that the Settings content pane gets generous breathing room (28px horizontal, 40px bottom clearance) and doesn't get overridden by `.modal-body`'s default `1rem`.
- Changed `.pane`, `.stage`, and `.section.on` to block layout with full content height so bottom padding is preserved when scrolling to the end of any tab.

### 6. Inline Save Actions in Settings Subsections
In `web/views/settings/sessions/resend.html` and `web/views/settings/sessions/authority.html`:
- Replaced sticky `.modal-foot` with `.section-actions` (`display: flex; justify-content: flex-end; margin-top: 1rem; padding-top: .4rem;`).
- Because Resend and Authority are subsections within the Sessions view rather than standalone modal views, their Save buttons now render inline at the foot of their respective forms rather than pinning a fake sticky footer across the bottom of the modal.
